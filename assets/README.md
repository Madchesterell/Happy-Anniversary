# Assets

Letakkan aset pribadi di folder ini. File sumber yang diterima belum menyertakan foto atau audio.

- Musik opsional: `bergema-sampai-selamanya.mp3` (sudah dirujuk oleh elemen audio di halaman).
- Foto hero: ubah SVG di `.hero-image` pada `index.html` menjadi `<img src="./assets/hero.webp" alt="Foto kita">`, lalu gunakan `object-fit: cover` pada `.hero-image img`.
- Foto arsip: ubah background `.memory-one .polaroid-image` sampai `.memory-four .polaroid-image` pada `css/style.css` menjadi `background-image: url("../assets/memory-1.webp")` dan set `background-size: cover; background-position: center;`.
