# The Art of Us — versi perbaikan interaksi

Website anniversary statis berbasis HTML, CSS, dan Vanilla JavaScript.

## Isi folder
- `index.html` — struktur halaman
- `styles.css` — seluruh tampilan dan tema Dark Warm Elegance, termasuk perbaikan tombol, navigasi chapter, dan flip archive card
- `app.js` — interaksi musik, chapter, kartu arsip, surat, lilin, dan daftar harapan
- `assets/` — tempat menambahkan aset foto/audio milik sendiri

## Menjalankan
Buka `index.html` di browser. Untuk hasil yang lebih konsisten, jalankan melalui ekstensi Live Server di VS Code.

## Aset opsional
- Musik: `assets/bergema-sampai-selamanya.mp3`
- Foto hero: ubah SVG di `.hero-image` pada `index.html` menjadi gambar sendiri.
- Foto arsip: ganti gradient pada `.memory-one` sampai `.memory-four .polaroid-image` di `styles.css` dengan foto sendiri.

Warna, font, dan susunan utama halaman dipertahankan. Perubahan hanya menargetkan radius/ukuran dua tombol utama, lapisan klik navigasi chapter, serta stabilitas flip 3D kartu arsip.
